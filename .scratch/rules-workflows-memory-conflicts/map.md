## Destination

รีโปที่ **ทุกข้อความเชิงกฎมีที่อยู่อย่างเป็นทางการเพียงที่เดียว** โดยมีลำดับศักดิ์ระหว่างชั้นเอกสารที่เขียนไว้ชัด และสำเนาที่ถูกแทนที่แล้วถูกลบทิ้งหรือเหลือเพียงตัวชี้ทาง — ไม่ใช่เอกสารที่ยังพูดกฎเวอร์ชันเก่าคู่ขนานไปกับฉบับจริง

ถึงปลายทางเมื่อ: รันสแกนหาข้อขัดแย้งซ้ำอีกครั้งแล้วได้ศูนย์ และไม่มีจุดใดที่ผู้อ่าน (คนหรือเอเจนต์) ต้องเดาเองว่าเอกสารสองฉบับที่ขัดกันฉบับไหนคือของจริง
