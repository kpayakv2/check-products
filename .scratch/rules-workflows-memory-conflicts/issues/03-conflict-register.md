## Question

ตอนตั้งแผนที่ได้ยืนยันข้อขัดแย้งไว้ ~15 จุด **จากการสุ่มดู ไม่ใช่การสแกนให้ครบ** ตั๋วนี้คืองานกวาดให้ครบทั้งสี่ชั้น แล้วออกมาเป็นทะเบียนเดียวที่ตั๋วอื่นใช้อ้างอิงได้

ไม่มีอะไรให้ตัดสินใจในตั๋วนี้ — แต่ตั๋วที่ต้องตัดสินใจ (โดยเฉพาะ [07: ถ้อยคำเดียวที่มาแทน "F1 ≥ 72%"](07-accuracy-rule-wording.md)) จะตัดสินบนข้อมูลไม่ครบถ้าไม่มีทะเบียนนี้ก่อน

## สิ่งที่ต้องกวาด

**ประเภทข้ออ้างที่ต้องตรวจกับของจริงทุกข้อ** — ห้ามเชื่อเอกสาร:
- ข้ออ้างเรื่อง **path** (ไฟล์/โฟลเดอร์ที่อ้างว่ามี — มีจริงไหม)
- ข้ออ้างเรื่อง **พอร์ตและโฮสต์** (`54331` / `54325` / `54323` / `8000` / `3000`, `127.0.0.1` vs `localhost`)
- ข้ออ้างเรื่อง **คำสั่งที่ให้รัน** (รันได้จริงไหม ชี้ไฟล์ที่มีอยู่ไหม)
- ข้ออ้างเรื่อง **ตัวเลขวัดผล** (72% / 72.3% / 25.5% / 79.5%)
- ข้ออ้างเรื่อง **สถานะงาน** ("ยังไม่แก้" / "แก้แล้ว" / "ยังไม่ merge")
- ข้ออ้างเรื่อง **เครื่องมือ MCP ที่บังคับใช้** เทียบกับที่มีอยู่จริงใน `.mcp.json`

**ขอบเขตไฟล์:** ทั้งสี่ชั้นตาม Notes ของแผนที่

## Resolution (2026-09-06)

**ทะเบียนฉบับเต็มอยู่ที่ [conflict-register.md](../conflict-register.md)** — ไม่ใส่ในตั๋วนี้เพราะยาวเกินและต้องให้ตั๋วอื่นลิงก์อ้างได้ตรงๆ

**สรุป:** กวาดครบ 4 ชั้นแล้ว พบ 23 จุดรวมของเดิม — แก้ไปแล้ว 11 จุด (3 จุดเป็นของใหม่ที่เจอระหว่างกวาด: `smart_impact_workflow.md` อ้าง Memory MCP/Puppeteer-Domscribe ที่ไม่มีจริง, `workflow-antigravity-verification.md` อ้าง spec ที่ตายไปแล้ว, `AGENTS.md` ตาราง Key Directories อ้าง `supabase/` ผิด path) เหลือเปิดอยู่ 12 จุด ทุกจุดมีตั๋วรออยู่แล้ว ไม่มีจุดไหนกำพร้า

**เกณฑ์ที่ตัดสินระหว่างทำ (สำคัญ เปลี่ยนขนาดงานอย่างมีนัย):**
1. รายงานที่ลงวันที่ชัดเจนใน `docs/reports/` ไม่นับเป็นข้อขัดแย้ง — เป็น Status ที่ถูกต้อง ณ เวลาที่บันทึก
2. พบกองเอกสารสถาปัตยกรรมเก่า **~25 ไฟล์** ใน `docs/development/`, `docs/architecture/`, `docs/reports/` ที่บรรยายระบบรุ่นก่อน Supabase/Next.js ทั้งดุ้น — ตรวจแล้วว่า `docs/INDEX.md` ไม่ได้ชี้เข้าไปเลยสักไฟล์ จึงไม่ใช่ข้อขัดแย้งที่ต้องแก้ในตั๋วนี้ (ไม่มีใครเดินผ่าน) แต่ชะตากรรมของกองนี้ทั้งก้อนยังไม่มีตั๋วตัดสิน — ถูกบันทึกไว้ใน "Not yet specified" ของแผนที่แล้ว
