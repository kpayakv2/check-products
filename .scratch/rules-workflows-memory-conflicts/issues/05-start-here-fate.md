## Question

## สภาพจริง (ยืนยันแล้ว 2026-09-05)

- บรรทัด 85 สั่ง `python api_server.py` ที่ระดับราก — ไฟล์ย้ายไป `src/api/api_server.py` แล้ว **ขัดกฎเหล็กข้อ 1 ("`src/` structure only") ของโปรเจกต์เอง**
- บรรทัด 241 พูดถึง `web_server.py` (Flask) ที่ "ยังใช้ FastAPI เหมือนเดิม" — **ไฟล์ไม่มีอยู่**
- บรรทัด 18/199/264 ยืนยัน "Accuracy 72%" ซึ่งเป็นตัวเลขปลอมที่ `CLAUDE.md` ประกาศยกเลิกแล้ว

## Resolution (2026-09-06)

ผู้ใช้เห็นด้วยกับคำแนะนำทั้ง 3 ข้อ:

1. **ทางเข้าสำหรับคน = `README.md`** (ธรรมเนียม GitHub, มีภาพรวม+Quick Start ที่ยังใช้งานได้จริงอยู่แล้ว) `docs/INDEX.md` ไม่ใช่คู่แข่ง แต่เป็นดัชนีชั้นที่สองเฉพาะโฟลเดอร์ `docs/`
2. **`START_HERE.md` ลบทิ้งเลย** ไม่ต้องเหลือ stub — ไม่มีเครื่องมือไหนอ่านชื่อไฟล์นี้อัตโนมัติ (ต่างจาก CLAUDE.md/GEMINI.md) และไม่มีไฟล์ไหนลิงก์เข้ามา ตรวจแล้วว่าปลอดภัย
3. **แก้ README.md ให้รับบทบาทเต็มตัว:**
   - เพิ่มลิงก์ไปหา `docs/INDEX.md` แทนการลิงก์เอกสารย่อยทีละไฟล์
   - พบและแก้ข้อขัดแย้งเพิ่ม (ไม่เคยอยู่ในทะเบียนตั๋ว 03): บรรทัด 62 เดิมระบุ Web UI = `http://127.0.0.1:3000` ขัดกับกฎจริงใน AGENTS.md ที่ต้องใช้ `localhost:3000` กัน CORS/cookie — แก้แล้ว พร้อมลิงก์กลับ AGENTS.md
   - ลบลายเซ็นเก่า "พัฒนาโดย: พยัคฆ์ (Gemini CLI Agent)" ที่ไม่สะท้อนความจริงหลายเครื่องมือแล้ว (ตามบรรทัดฐานเดียวกับที่ลบออกจาก `docs/INDEX.md` ในตั๋ว 01)
   - ตรวจแล้วว่า README.md ไม่มีตัวเลข 72% แบบบังคับ (มีแค่ 72.3% ที่วัดจริง อ้างอิงเทสต์จริง — เป็น Status ไม่ใช่ Rule ปลอม) และคำสั่ง `python -m src.api.api_server` รันได้จริง (ตรวจ `__main__` block แล้ว)
