## Question

ตัวเลข **"72%"** กระจายไปทั่วรีโปในสามความหมายที่ต่างกัน จะยุบเหลือ **ข้อความเดียว เก็บที่เดียว** ว่าอย่างไร และที่เหลือทั้งหมดจะกลายเป็นอะไร

สามความหมายที่ปนกันอยู่ตอนนี้:
1. **เกณฑ์บังคับ** — "ห้ามต่ำกว่า 72%" (กฎที่ต้องผ่านก่อน commit)
2. **ค่าที่วัดได้** — 72.3% บน test set 595 รายการ เมื่อ 2026-08-26
3. **ตัวเลขปลอม** — 72% ที่ `tests/benchmark_similarity.py` เคย print แบบ hardcode โดยไม่ได้จัดหมวดอะไรเลย (ไฟล์ถูกลบแล้ว)

เอกสารเก่าแทบทุกฉบับพูดแบบที่ 1 หรือ 3 โดยไม่รู้ตัว

## ทำไมต้องรอ [03](03-conflict-register.md)

ตอนตั้งแผนที่นับเจอ 12+ จุด แต่ยังไม่ได้กวาดให้ครบ การตัดสินถ้อยคำโดยไม่รู้ว่าต้องไปแก้กี่จุดและอยู่ชั้นไหนบ้าง จะได้ถ้อยคำที่แก้ไม่ครบ
