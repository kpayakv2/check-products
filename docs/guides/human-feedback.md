# 🤖 Human-in-the-Loop & Machine Learning Guide

คู่มือการตรวจงาน AI และการสอนให้ AI ฉลาดขึ้นตามสไตล์คุณกาน

---

## 🔍 1. ระบบตรวจงาน (Human Review)

เมื่อ AI มีคะแนนความมั่นใจอยู่ในช่วง **0.70 - 0.89** ระบบจะส่งรายการเข้าสู่คิวรอตรวจ:

*   **ผ่าน Web UI**: เข้าไปที่ Port 3000 เมนู "Review Queue"
*   **ผ่าน Terminal**: รันคำสั่ง `python complete_deduplication_pipeline.py --mode review`

### **การให้ Feedback 4 ระดับ:**
1.  **Duplicate (ซ้ำ)**: สินค้าตัวเดียวกันเป๊ะ (AI จะจำคู่ลักษณะนี้ไว้)
2.  **Similar (คล้ายแต่ไม่ซ้ำ)**: เช่น ต่างขนาด, ต่างสี, หรือต่างรุ่น
3.  **Different (ต่างกัน)**: คนละประเภทสินค้าเลย
4.  **Not Sure (ไม่แน่ใจ)**: เก็บไว้ปรึกษาทีมงานต่อ

---

## 🧠 2. การสอน AI (Machine Learning Feedback)

ทุกครั้งที่คุณกานกดเลือก (Feedback) ข้อมูลจะถูกเก็บลงใน `product_deduplication.db`:

*   **วิธีรัน Training**: 
    ```bash
    python complete_deduplication_pipeline.py --mode train
    ```
*   **ผลลัพธ์**: ระบบจะสร้างไฟล์ `deduplication_model.joblib` ซึ่งเป็น "สมองส่วนเสริม" ที่ช่วยปรับจูนคะแนน Hybrid ให้แม่นยำยิ่งขึ้น

---

## 🔌 3. Endpoints สำหรับนักพัฒนา (FastAPI)

หากต้องการเชื่อมต่อระบบ Review กับแอปอื่น ให้ใช้ Endpoints เหล่านี้ (Port 8000):

*   **ดึงรายการรอตรวจ**: `GET /api/v1/jobs`
*   **ส่งผลการตรวจ**: `POST /api/v1/match/single` (ใช้สำหรับตรวจสอบรายชิ้น)
*   **เช็คสถานะการ Train**: `GET /api/v1/health`

---

## 📈 4. ประโยชน์ของการให้ Feedback
*   **ลดงานซ้ำซ้อน**: AI จะไม่ถามซ้ำในคู่สินค้าเดิมที่เคยตรวจไปแล้ว
*   **เพิ่มความแม่นยำ**: ระบบจะเข้าใจคำพ้องความหมาย (Synonyms) เฉพาะตัวของคุณกานได้ดีขึ้น
*   **Auto-Approve สูงขึ้น**: เมื่อ AI ฉลาดขึ้น รายการที่ต้องตรวจด้วยมือจะลดลงเรื่อยๆ
